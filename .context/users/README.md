# User Intent & Prompt Logs Directory
> **Rule Reference:** [.agents/rules/user_logging.md](file:///c:/Users/anshul%20prajapati/OneDrive/Desktop/Snoopy/.agents/rules/user_logging.md)

This directory contains dedicated markdown files for every contributor/user on the Snoopy project (formatted as `<username>.md`).

## Purpose
- Maintain an append-only historical log of all user prompts, instructions, explanations, and intent.
- Ensure that whoever is working on Snoopy has their goals, constraints, and discussions clearly recorded.
- Provide full provenance for every feature decision, prompt iteration, and architecture choice.

## Naming Convention
Files are named using the contributor's sanitized username (lowercase snake_case):
- `anshul_prajapati.md`
- `contributor_name.md`
