# Snoopy 

**A scam-checking tool by DETOX.**

Snoopy is a project in development that aims to help people identify potential scams and recognize suspicious activity online.

## What Snoopy Aims to Do

 **Detect Red Flags** — Help identify common warning signs of online scams and fraud.
 **Check Suspicious Links** — Help users assess potentially malicious or deceptive URLs.
 **Analyze Suspicious Messages** — Help recognize scam patterns in messages and online communications.
 **Promote Online Safety** — Provide understandable findings to help people make informed decisions.

##  Project Status

Snoopy is currently under development. Features, detection methods, and usage instructions will be documented as they become available.

##  Disclaimer

Snoopy is designed to assist with scam awareness and detection. It cannot guarantee that a website, link, or message is safe or fraudulent.

Always exercise caution when sharing personal information, sending money, or responding to requests for passwords and one-time passwords (OTPs). Verify suspicious requests through official channels.
